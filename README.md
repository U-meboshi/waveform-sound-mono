Unified Mono Signal Generator

Features:
- Shared frequency, waveform selection, and volume
- Always-visible waveform preview for Sine, Square, Triangle, Sawtooth, and Custom Draw
- Custom waveform drawing editor, repeat cycles, smoothing, normalization
- Mono output to both left and right speakers
- Responsive desktop/mobile layout

Deploy by replacing index.html and sketch.js in the GitHub Pages repository.
JavaScript syntax was checked; real device audio testing was not performed.
